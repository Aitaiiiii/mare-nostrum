# Inotrope & Vasopressor Infusions — Reference Orders

> [!danger] ⚠️ SAFETY
> Reference only; adjust to local protocol, pump/concentration standards, and the attending. **Choose the agent by shock type** (see [[Approach - Undifferentiated Shock]]): distributive → noradrenaline first; cardiogenic → inotrope ± vasopressor. **Give via a central line where possible** (extravasation → tissue necrosis; phentolamine/terbutaline for extravasation); titrate to MAP ≥ 65 + perfusion. Correct hypovolaemia first.

## 🔵 Agent reference (titrate to effect; concentrations per local protocol)

| Agent | Class / effect | Typical starting dose | Usual range | First-line for |
|---|---|---|---|---|
| **Noradrenaline (norepinephrine)** | α > β; vasopressor | 0.05 µg/kg/min (≈ 2–8 µg/min) | 0.05–0.5+ µg/kg/min | **Septic/distributive shock (1st-line)**, most undifferentiated shock |
| **Adrenaline (epinephrine)** | α + β; ino-vasopressor | 0.05 µg/kg/min | 0.05–0.5 µg/kg/min | Anaphylaxis (infusion if refractory), cardiac arrest (bolus), 2nd-line septic/cardiogenic |
| **Vasopressin** | V1 vasopressor | fixed 0.03 U/min (not titrated) | 0.03 (–0.04) U/min | Add-on in septic shock (noradrenaline-sparing) |
| **Dobutamine** | β1 inotrope (± vasodilator) | 2.5 µg/kg/min | 2.5–20 µg/kg/min | Cardiogenic shock / low-output HF (warm-cold), can drop BP |
| **Milrinone** | PDE3 inhibitor inodilator | 0.125 µg/kg/min (± no bolus) | 0.125–0.75 µg/kg/min | Cardiogenic shock, RV failure/PH; renally cleared (accumulates in AKI) |
| **Dopamine** | dose-dependent | 5 µg/kg/min | 5–20 µg/kg/min | Bradycardia/2nd-line (more arrhythmia than noradrenaline) |
| **Phenylephrine** | pure α | 0.5 µg/kg/min (or 40–100 µg bolus) | titrate | Vasodilatory shock with tachyarrhythmia; peri-procedural hypotension |
| **Dexmedetomidine** | α2 agonist (sedation, not a pressor) | 0.2–0.7 µg/kg/h | — | Sedation/autonomic (NOT for shock BP support) |

## 🔴 One Day
- [ ] Establish the shock type ([[Approach - Undifferentiated Shock]]); ensure adequate volume resuscitation first (fluid-responsiveness-guided)
- [ ] **Arterial line + central venous access** (central line preferred for vasopressors); continuous ECG/BP; hourly urine output
- [ ] Start the appropriate agent at the low end and **titrate to MAP ≥ 65 mmHg + perfusion (lactate clearance, urine output, mentation)**
- [ ] Septic shock: **noradrenaline first-line → add vasopressin 0.03 U/min → consider adrenaline/steroid** if refractory (see [[Sepsis (Sepsis-3)]])
- [ ] Cardiogenic shock: **inotrope (dobutamine/milrinone) ± noradrenaline**; consider [[MCS (Mechanical Circulatory Support)]]

## 🔵 Continuous
- [ ] Titrate to targets; monitor for tachyarrhythmia, ischaemia, digit/gut ischaemia, hyperglycaemia (adrenaline), extravasation
- [ ] Wean as shock resolves (usually vasopressin/adrenaline off first per protocol); daily lactate/perfusion review
- [ ] Treat the underlying cause; ICU care

> [!info]- Why
> Agent choice follows physiology: distributive shock needs vasoconstriction (noradrenaline ± vasopressin), cardiogenic shock needs inotropy (dobutamine/milrinone) often with a pressor; dopamine causes more arrhythmia and phenylephrine is niche. Central delivery + titration to MAP/perfusion avoids both under-treatment and extravasation/ischaemia. Verified vs Surviving Sepsis 2021 + critical-care standards.
