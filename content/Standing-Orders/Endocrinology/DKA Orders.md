# DKA — Admission Orders

> [!danger] ⚠️ SAFETY
> Reference only; adjust to local protocol and the attending. **Fluids + potassium before/with insulin.** **Hold insulin if K⁺ < 3.3** until replaced. Add dextrose when glucose ~ 200–250 to keep insulin running until the anion gap closes. Find the precipitant (infection, non-adherence, MI, new T1DM, SGLT2i → euglycaemic DKA). Beware cerebral oedema (esp. children).

## 🔴 One Day
- [ ] Confirm DKA: **glucose > 250 (may be near-normal with SGLT2i), pH < 7.3 / HCO₃ < 18, ketonaemia/ketonuria, raised anion gap**
- [ ] Labs: VBG/ABG, **electrolytes + anion gap, glucose, β-hydroxybutyrate/ketones, BUN/Cr, phosphate, magnesium**, CBC, ECG (K⁺); septic screen/precipitant work-up (CXR, urine, cultures, troponin)
- [ ] **Fluids: 0.9% NaCl ~15–20 mL/kg (1–1.5 L) in the first hour**, then adjust to hydration/corrected Na⁺ (switch to 0.45% NaCl if corrected Na normal/high); **add 5% dextrose when glucose ≤ ~200–250**
- [ ] **Potassium:** K⁺ < 3.3 → **hold insulin, give KCl 20–30 mmol/h** until ≥ 3.3; K⁺ 3.3–5.3 → **add 20–30 mmol KCl per litre**; K⁺ > 5.3 → no KCl, recheck
- [ ] **Insulin: regular insulin infusion 0.1 U/kg/h** (± 0.1 U/kg IV bolus) — start after the first fluid bolus and once K⁺ ≥ 3.3; target glucose fall ~50–75 mg/dL/h
- [ ] **Bicarbonate only if pH < 6.9** (per protocol); replace phosphate/magnesium only if severe/symptomatic
- [ ] Hourly glucose; electrolytes/VBG q2–4h; strict I/O + urinary catheter if needed

## 🔵 Continuous
- [ ] Admit (ICU if severe/altered mentation) — Dx: DKA (precipitant ___)
- [ ] Continue insulin infusion + dextrose-containing fluids **until anion gap normalises / ketones clear** (not just until glucose normal); monitor gap closure
- [ ] **Transition to subcutaneous insulin with 1–2 h overlap** once eating, anion gap closed, HCO₃ ≥ 15/pH > 7.3
- [ ] Treat the precipitant; diabetes education; **restart/adjust home insulin**; hold SGLT2i (euglycaemic DKA)
- [ ] Watch for cerebral oedema (headache/↓GCS — children), hypokalaemia, hypoglycaemia, fluid overload

> [!info]- Why
> DKA is a deficit of insulin + volume + potassium; fluids restore perfusion, insulin switches off ketogenesis, and potassium must precede/accompany insulin (which drives K⁺ intracellularly and can cause fatal hypokalaemia). Dextrose is added so insulin keeps running to close the anion gap even after glucose normalises. Bicarbonate is reserved for pH < 6.9. Verified vs ADA/Thai DKA (TSPE 2565).
