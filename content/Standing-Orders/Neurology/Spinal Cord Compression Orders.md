# Spinal Cord Compression / Cauda Equina — ER Orders

> [!danger] ⚠️ SAFETY
> Reference only; adjust to local protocol and the attending. **New back pain + neurology (weakness / sensory level / bladder-bowel / saddle anaesthesia) = emergency → whole-spine MRI + dexamethasone now.** Deficit at treatment predicts recovery — do not wait for paralysis/retention. Image the WHOLE spine (skip lesions).

## 🔴 One Day
- [ ] **Dexamethasone 16 mg/day (16 mg OD or 8 mg BD) IV/PO STAT** (MSCC) + **PPI** + glucose monitoring
- [ ] **Urgent whole-spine MRI within 24 h** (CT/CT-myelogram if MRI contraindicated)
- [ ] **Post-void residual / bladder scan**; catheterise if retention
- [ ] **Urgent referral: neurosurgery + radiation oncology (± oncology)** — decide surgery ± RT vs RT alone
- [ ] Labs: CBC, electrolytes, calcium, renal/liver, coagulation; if new cancer → **PSA, SPEP/free light chains**, staging CT; if abscess suspected → CRP, blood cultures, contrast MRI
- [ ] Analgesia; spinal precautions/immobilisation if unstable; **VTE prophylaxis** (mechanical ± pharmacological)
- [ ] **Cauda equina from disc → emergency neurosurgical decompression** (window short, ideally < 24–48 h)
- [ ] **Epidural abscess / unstable fracture → emergency surgery**; **spinal TB (Pott's) → anti-TB ± surgery**

## 🔵 Continuous
- [ ] Admit (neurosurgery/oncology) — Dx: cord compression / cauda equina (cause ___, level ___)
- [ ] Serial neuro obs (power, sensory level, anal tone, bladder function)
- [ ] Continue dexamethasone (taper per definitive treatment); PPI; glucose control
- [ ] Bladder/bowel care, pressure-area care, physiotherapy
- [ ] Identify + treat primary malignancy (systemic therapy); complete staging
- [ ] Rehabilitation planning; palliative-care involvement where appropriate

> [!info]- Why
> Cord/root ischaemia becomes irreversible, and pre-treatment function predicts recovery, so dexamethasone (reduces oedema) + rapid MRI + definitive decompression must beat the deficit becoming fixed; whole-spine imaging catches common skip metastases. Surgery + RT beats RT alone in suitable single-level MSCC (Patchell). Abscess/unstable fracture and disc cauda equina are surgical emergencies. Verified vs MSCC guidance + Patchell.
