# Altered Mental Status / Coma — ER Orders

> [!danger] ⚠️ SAFETY
> Reference only; adjust to local protocol and the attending. **Check glucose (DEFG — Don't Ever Forget Glucose) + give universal reversibles first.** **GCS ≤ 8 → protect the airway.** **Fever + AMS → empiric antibiotics + aciclovir NOW (don't wait for LP).** CT before LP if focal signs/↑ICP. Full framework: [[Approach - Altered Mental Status & Coma]].

## 🔴 One Day
- [ ] ABCs; **GCS + pupils + focal neuro**; **capillary glucose STAT** (correct hypoglycaemia); O₂ to SpO₂ ≥ 94%; **GCS ≤ 8 → intubate**
- [ ] **Universal reversibles:** **glucose** (50% dextrose 25–50 mL IV if low) · **thiamine 100 mg IV before glucose if alcoholic/malnourished** · **naloxone 0.4–2 mg** for opioid picture
- [ ] Labs: CBC, **electrolytes (Na/K/Ca/Mg), BUN/Cr, glucose, LFT, ammonia**, VBG/ABG (+ CO-Hb), **toxicology + paracetamol/salicylate**, TFT/cortisol as indicated, blood cultures if febrile; ECG
- [ ] **CT brain non-contrast** — before LP if focal signs/papilloedema/↓GCS/trauma/anticoagulation
- [ ] **[Fever + AMS / meningism] empiric ceftriaxone 2 g IV q12h + ampicillin 2 g IV q4h (> 50/immunocompromised) + dexamethasone + aciclovir 10 mg/kg IV q8h — BEFORE LP** (see [[Bacterial Meningitis]] · [[HSV Encephalitis]]); then **LP** (cell count, protein, glucose, Gram/culture, HSV PCR, CrAg/India ink)
- [ ] **Specific antidotes:** benzodiazepine OD → flumazenil (caution — seizures); alcohol-withdrawal DT → diazepam/CIWA; Wernicke → thiamine 500 mg IV tid; raised ICP/herniation → HOB 30°, hypertonic saline/mannitol, brief hyperventilation, neurosurgery

## 🔵 Continuous
- [ ] Admit (ICU if ↓GCS/unstable) — Dx: altered mental status (cause ___)
- [ ] Serial neuro obs + GCS; **EEG if not waking** (non-convulsive status epilepticus); repeat CT for deterioration
- [ ] Treat the identified cause (metabolic/toxic/infective/structural — AEIOU-TIPS); correct electrolytes/glucose; supportive care

> [!info]- Why
> AMS/coma has many rapidly-reversible causes, so the reflex is resuscitate + glucose/thiamine/naloxone + a broad metabolic/tox/infective screen, with a CT-then-LP pathway and empiric antimicrobials-before-tap when CNS infection is possible. The exam separates structural (focal) from metabolic/toxic (symmetric). Verified vs emergency-neurology standards.
