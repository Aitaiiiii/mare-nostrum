# Priapism — ER Orders

> [!danger] ⚠️ SAFETY
> Reference only; adjust to local urology protocol. **Ischaemic priapism (painful, rigid, dark corporal gas) is an emergency → aspiration + intracavernosal phenylephrine NOW** — delay causes permanent ED. Distinguish ischaemic from non-ischaemic. Monitor BP/pulse with phenylephrine.

## 🔴 One Day
- [ ] Assess: erection **> 4 h**, pain/rigidity; **corporal blood-gas aspirate** (dark/acidotic = ischaemic; bright/arterial = high-flow) ± colour Doppler
- [ ] CBC + **haemoglobinopathy screen (sickle/thalassaemia)**; drug history; toxicology
- [ ] **[ISCHAEMIC] Local anaesthesia → corporal aspiration (± saline irrigation) + intracavernosal phenylephrine** — dilute 100–500 µg/mL, **100–200 µg every 5 min**, up to ~1 h / **1000 µg total**, with **BP/pulse/ECG monitoring**
- [ ] Treat cause in parallel (do NOT delay local treatment): **sickle/Hb — hydration, O₂, analgesia, haematology** (exchange transfusion if refractory); stop precipitant drugs
- [ ] **Refractory to aspiration + phenylephrine → urology for surgical shunt**
- [ ] **[NON-ISCHAEMIC/high-flow] not an emergency** — observe; selective arterial embolisation if persistent

## 🔵 Continuous
- [ ] Admit/observe per severity — Dx: priapism (ischaemic/non-ischaemic)
- [ ] Monitor detumescence, cardiovascular status (phenylephrine), and for recurrence
- [ ] Urology follow-up; counsel on erectile-function outcome (time-dependent); manage underlying cause (Hb disorder, drugs)

> [!info]- Why
> Ischaemic priapism is a penile compartment syndrome — corporal aspiration relieves pressure and intracavernosal phenylephrine (α-agonist) restores venous outflow, salvaging erectile function if done early; treating the cause (e.g. sickle cell) is adjunctive and must not delay local therapy. Non-ischaemic priapism is arterial and not emergent. Verified vs AUA/SMSNA 2022.
