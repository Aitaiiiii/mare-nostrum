# Neurotoxic Snakebite — ER Orders

> [!danger] ⚠️ SAFETY
> Reference only; adjust to local/QSMI protocol and the attending. **Respiratory failure is the killer — intubate/ventilate early.** Krait bites look trivial and paralyse hours later → observe long. Advice: **Ramathibodi Poison Center 1367 / QSMI**. Exclude haemotoxic envenoming (20-min WBCT).

## 🔴 One Day
- [ ] ABC; O₂; **anticipate + treat respiratory failure — intubate/ventilate (or BVM) at first ventilatory/bulbar weakness** (falling vital capacity/single-breath count)
- [ ] Serial neuro checks: **ptosis, extra-ocular movements, single-breath count, neck-lift, RR, SpO₂, vital capacity**
- [ ] First aid: **pressure-immobilisation bandage + splint** (elapid); remove rings; **NO tourniquet/incision/suction**
- [ ] **20-minute whole-blood clotting test (20-min WBCT)** + CBC/platelets, coagulation, renal function, CK, electrolytes (Na⁺ — krait) — exclude haemotoxic envenoming
- [ ] **Neuro Polyvalent antivenom (QSMI)** IV for neurotoxic signs / progressing dangerous-species bite — **have adrenaline, hydrocortisone, antihistamine ready for anaphylaxis**; repeat if progressing
- [ ] **Anticholinesterase trial: Atropine 0.6 mg IV, then Neostigmine 1.5–2.5 mg IV/SC** — continue if responds (cobra/postsynaptic); poor response expected for krait
- [ ] **Tetanus prophylaxis**; wound care; identify snake (photo) if safe
- [ ] Antibiotics only if secondary infection; analgesia

## 🔵 Continuous
- [ ] Admit (ICU/monitored if any neurotoxicity or krait/cobra bite) — Dx: neurotoxic snakebite (species ___)
- [ ] Continue ventilatory support until neuromuscular recovery (full recovery expected, esp. krait, with support)
- [ ] Continue neostigmine if effective; repeat antivenom for ongoing progression
- [ ] **Prolonged observation for asymptomatic/krait bites** — delayed paralysis (many hours) before safe discharge
- [ ] Wound review/debridement for cobra local necrosis; monitor Na⁺ (krait), renal function
- [ ] Serum-sickness counselling after antivenom; discharge advice + follow-up

> [!info]- Why
> Death is from ventilatory failure, and patients recover completely with airway support, so early intubation is the priority. Antivenom (QSMI Neuro Polyvalent) halts progression; neostigmine reverses postsynaptic (cobra) block but not presynaptic (krait). Krait envenoming is deceptively delayed, so long observation is mandatory. Always exclude concurrent haemotoxic envenoming. Verified vs QSMI/Thai snakebite practice.
