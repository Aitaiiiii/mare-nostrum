# Sepsis & Septic Shock — Admission Orders

> [!danger] ⚠️ SAFETY
> Reference only; adjust to local antibiogram and the attending. **Sepsis-3: suspected infection + organ dysfunction (SOFA ↑ ≥ 2 / qSOFA); septic shock = vasopressor need + lactate > 2 despite fluids.** Deliver the **1-hour bundle**. In Thailand cover **melioidosis** (ceftazidime/carbapenem) in the at-risk (diabetic, NE Thailand). Blood cultures BEFORE antibiotics, but don't delay antibiotics.

## 🔴 One Day — Surviving Sepsis 1-hour bundle
- [ ] **Measure lactate** (repeat if > 2 to guide resuscitation)
- [ ] **Blood cultures ×2 (+ site cultures) BEFORE antibiotics** (do not delay antibiotics > 45 min for them)
- [ ] **Broad-spectrum antibiotics within 1 hour** — empiric by source + local antibiogram (e.g. ceftriaxone/pip-tazo/carbapenem ± vancomycin); **Thailand: cover melioidosis (ceftazidime 2 g IV q8h or meropenem) in at-risk**; antifungal if candidaemia risk
- [ ] **IV crystalloid 30 mL/kg for hypotension or lactate ≥ 4** (balanced crystalloid; reassess with dynamic fluid-responsiveness — avoid over-resuscitation)
- [ ] **Vasopressor if MAP < 65 after fluids → noradrenaline first-line** (target MAP ≥ 65; add vasopressin, then adrenaline/steroid if refractory — see [[Inotrope & Vasopressor Infusions]])
- [ ] **Source control** — identify + drain/remove (abscess, obstructed kidney/biliary, infected line, empyema, necrotising infection) urgently
- [ ] Labs: CBC, electrolytes, BUN/Cr, LFT, coagulation/DIC, glucose, procalcitonin, VBG; ECG; imaging to find the source; O₂/airway support

## 🔵 Continuous
- [ ] Admit (ICU if shock/organ failure) — Dx: sepsis / septic shock (source ___)
- [ ] **Reassess perfusion + repeat lactate** (target clearance); titrate fluids/vasopressors to MAP ≥ 65, urine output, mentation
- [ ] **De-escalate antibiotics on culture/sensitivity**; set duration (usually 7 days; longer for undrained/specific sources — melioidosis: intensive IV then months of oral eradication)
- [ ] **[Refractory shock] hydrocortisone 200 mg/day IV**; glucose control; lung-protective ventilation if ARDS; RRT for AKI indications; VTE + stress-ulcer prophylaxis; nutrition
- [ ] Daily source-control review; monitor organ function

> [!info]- Why
> Early antibiotics + source control + perfusion restoration (fluids then noradrenaline, guided by lactate/MAP) drive sepsis survival; the 1-hour bundle operationalises this. Thailand's differentiator is melioidosis, which standard β-lactams miss. De-escalation limits resistance. Verified vs Surviving Sepsis Campaign 2021 + Thai sepsis CPG 2026.
