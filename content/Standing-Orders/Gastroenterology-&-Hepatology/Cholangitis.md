# Acute Cholangitis — Admission Orders

> [!danger] ⚠️ SAFETY
> Reference only; adjust to local antibiogram and the attending. **The definitive treatment is biliary drainage** — antibiotics alone do not cure an obstructed infected biliary tree. **Severe (Grade III, organ dysfunction) → resuscitate + antibiotics + URGENT drainage (ERCP).** Charcot's triad (fever + RUQ pain + jaundice) → Reynolds' pentad (+ shock + confusion) = severe.

## 🔴 One Day
- [ ] Diagnose (Tokyo Guidelines): **systemic inflammation (fever/labs) + cholestasis (jaundice/↑ALP/GGT/bilirubin) + imaging (biliary dilatation/obstruction)**; grade severity (I mild / II moderate / III severe = organ dysfunction)
- [ ] Labs: CBC, **LFT (obstructive pattern), bilirubin**, electrolytes, BUN/Cr, **lactate**, coagulation, amylase/lipase (concurrent pancreatitis), **blood cultures ×2**
- [ ] **Imaging: US** first → **MRCP/CT** to define the level/cause (stone/stricture/tumour)
- [ ] **IV fluids resuscitation** + analgesia; NPO; treat sepsis ([[Sepsis (Sepsis-3)]])
- [ ] **Empiric IV antibiotics (Gram-negative + anaerobe): ceftriaxone + metronidazole, or piperacillin-tazobactam / carbapenem** (broaden for healthcare-associated/severe; cover ESBL per local rate)
- [ ] **Biliary drainage — ERCP with sphincterotomy/stone extraction/stent:** **URGENT (< 24 h) for severe (Grade III) or non-responding**; early/elective for mild-moderate responding to antibiotics; **PTBD or surgery if ERCP fails/unavailable**

## 🔵 Continuous
- [ ] Admit (ICU if Grade III/shock) — Dx: acute cholangitis (Tokyo Grade ___, cause ___)
- [ ] Reassess response; **de-escalate antibiotics on culture**; total course ~4–7 days after source control (longer for bacteraemia/residual)
- [ ] Monitor LFT/bilirubin trend, sepsis parameters; manage concurrent gallstone pancreatitis ([[Acute Pancreatitis]])
- [ ] **Definitive: cholecystectomy** for gallstone disease after recovery (interval); manage stricture/malignancy per cause

> [!info]- Why
> Cholangitis is a closed-space infection of an obstructed biliary tree, so the cure is drainage (ERCP) with antibiotics as adjunct; severe disease needs urgent decompression because it progresses to septic shock rapidly. Cultures + de-escalation limit resistance. Verified vs Tokyo Guidelines (TG18).
