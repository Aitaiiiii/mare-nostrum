# TTP & HUS (TMA) — Admission Orders

> [!danger] ⚠️ SAFETY
> Reference only; adjust to local protocol and the attending. **MAHA + thrombocytopenia unexplained = TTP → urgent plasma exchange, don't wait for ADAMTS13.** **NEVER transfuse platelets in TTP** (except life-threatening bleeding). **STEC-HUS: avoid antibiotics/antimotility.** Involve haematology immediately.

## 🔴 One Day
- [ ] **CBC + blood film (schistocytes)**, reticulocytes; **LDH, indirect bilirubin, haptoglobin, DAT (Coombs)**; renal function, urinalysis; **PT/aPTT/fibrinogen (normal → not DIC)**
- [ ] **ADAMTS13 activity + inhibitor — send BEFORE plasma exchange** (< 10% confirms TTP); **PLASMIC score**
- [ ] Stool STEC/Shiga toxin if diarrhoeal; complement studies if aHUS suspected; pregnancy test; exclude DIC/HELLP/malignant HTN/sepsis
- [ ] **[TTP — clinical suspicion/high PLASMIC] Start therapeutic plasma exchange URGENTLY** (daily); **plasma infusion as a bridge** if PEX delayed
- [ ] **Corticosteroids**; **caplacizumab** where available; haematology referral
- [ ] **DO NOT transfuse platelets** (except catastrophic bleeding/critical procedure); **RBC transfusion + folate** as needed
- [ ] **[STEC-HUS] supportive — fluids/renal support; AVOID antibiotics + antimotility agents**
- [ ] **[atypical HUS] eculizumab** (meningococcal vaccination/prophylaxis first)

## 🔵 Continuous
- [ ] Admit (ICU if neuro/organ compromise) — Dx: TMA (?TTP/?HUS)
- [ ] Continue **daily plasma exchange until platelets > 150 + haemolysis resolves (LDH normalising)**; taper per haematology
- [ ] **Rituximab** for refractory/relapsing acquired TTP
- [ ] Manage AKI (dialysis if needed); monitor neuro status, platelets, LDH
- [ ] Relapse surveillance (acquired TTP); treat underlying trigger

> [!info]- Why
> TTP is rapidly fatal untreated but responds to plasma exchange (removes antibody + ultra-large vWF, replaces ADAMTS13), so treatment starts on clinical grounds before the ADAMTS13 result. Platelet transfusions fuel microvascular thrombosis and are avoided. STEC-HUS antibiotics increase toxin release/HUS; aHUS needs complement blockade. Verified vs TTP/TMA guidance.
