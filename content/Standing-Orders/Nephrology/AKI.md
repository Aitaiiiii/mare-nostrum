# Acute Kidney Injury — Admission Orders

> [!danger] ⚠️ SAFETY
> Reference only; adjust to local protocol and the attending. **Treat hyperkalaemia urgently** (ECG → calcium → shift → remove). **Always exclude obstruction** (bladder scan + renal US) — post-renal AKI is reversible. **Stop nephrotoxins + renally dose all drugs.** Dialyse for a refractory **AEIOU** indication, not by number.

## 🔴 One Day
- [ ] Stage (KDIGO): ↑Cr ≥ 0.3 mg/dL/48 h or ≥ 1.5× baseline/7 d, or UOP < 0.5 mL/kg/h ≥ 6 h
- [ ] **Classify pre-renal / intrinsic / post-renal**: volume assessment, **urinalysis + microscopy** (muddy-brown casts = ATN; RBC casts = GN; WBC/eos = AIN), **FeNa/FeUrea**, urine electrolytes
- [ ] **Bladder scan + renal ultrasound — exclude obstruction/hydronephrosis** (catheterise if retention)
- [ ] Labs: electrolytes (**K⁺**), venous gas/HCO₃, calcium/phosphate, CBC, **CK + urine myoglobin** if rhabdo suspected; ECG (hyperkalaemia); GN screen (ANCA/anti-GBM/complement) if indicated
- [ ] **Restore perfusion:** isotonic crystalloid for hypovolaemic/pre-renal (to euvolaemia — avoid over-resuscitation); treat sepsis/shock; **relieve obstruction**
- [ ] **Stop nephrotoxins** (NSAIDs, ACE-I/ARB, aminoglycosides, contrast); **renally dose-adjust all drugs**
- [ ] **Treat hyperkalaemia** (see [[Dyskalemia (Hypo- & Hyperkalemia)]]) + acidosis (bicarbonate if severe)

## 🔵 Continuous
- [ ] Admit — Dx: AKI (KDIGO stage ___, pre-/intrinsic/post-renal)
- [ ] Daily weight, strict I/O; daily electrolytes, creatinine, gas; fluid balance (avoid overload)
- [ ] **RRT for AEIOU** (refractory Acidosis, Electrolytes/hyperkalaemia, Intoxication, Overload, Uraemia) — no benefit to early prophylactic dialysis
- [ ] Nutrition; avoid hypotension; treat cause (disease-specific therapy for GN/TMA; AIN → stop drug ± steroid)
- [ ] Nephrology referral for GN/unclear cause/RRT; AKI → CKD follow-up
- [ ] **[Thailand] febrile AKI → screen leptospirosis/dengue/malaria/snakebite**

> [!info]- Why
> AKI management is: fix perfusion, relieve obstruction, stop nephrotoxins, and treat the lethal complications (hyperkalaemia first) — dialysing only for a refractory AEIOU indication (AKIKI/STARRT-AKI showed no benefit to early RRT). Urinalysis + FeNa + ultrasound are the high-yield first tests. Verified vs KDIGO AKI.
