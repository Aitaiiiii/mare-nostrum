# Rhabdomyolysis — ER Orders

> [!danger] ⚠️ SAFETY
> Reference only; adjust to local protocol and the attending. **Start aggressive isotonic fluids early (before AKI).** Hyperkalaemia can cause cardiac arrest — ECG + treat urgently. Bicarbonate/mannitol NOT routine. Watch/decompress compartment syndrome.

## 🔴 One Day
- [ ] **Isotonic saline (or Ringer's lactate) — start ~400 mL/h**, titrate to **urine output 1–3 mL/kg/h (up to ~300 mL/h)**; crush syndrome → UOP 200–300 mL/h; monitor for overload
- [ ] **CK** (diagnosis: > 5× ULN / > 1000), **electrolytes (K⁺!), calcium, phosphate, urate**, BUN/Cr, venous gas, CBC, coagulation
- [ ] Urinalysis (**dipstick blood + no RBCs = myoglobinuria**)
- [ ] **ECG + treat hyperkalaemia** (calcium → insulin-dextrose + salbutamol → removal) — see [[Dyskalemia (Hypo- & Hyperkalemia)]]
- [ ] **Hypocalcaemia — treat only if symptomatic or severe hyperkalaemia** (rebound hypercalcaemia risk)
- [ ] **Do NOT routinely alkalinise/give mannitol** (consider bicarbonate only if urine pH < 6.5 + adequate output)
- [ ] Strict I/O + urinary catheter; identify cause (crush, statin, heat, seizure, toxin, ischaemia)
- [ ] **Assess for compartment syndrome → surgical fasciotomy**

## 🔵 Continuous
- [ ] Admit (ICU if severe/AKI/hyperK) — Dx: rhabdomyolysis (cause ___)
- [ ] Continue fluids titrated to UOP; **trend CK** (continue until falling toward normal), K⁺, Ca, phosphate, renal function
- [ ] Manage as [[Acute Kidney Injury]] if AKI; **RRT for AEIOU** (refractory hyperK/acidosis/overload/uraemia)
- [ ] Treat the precipitant (stop statin/offending drug, cool if hyperthermic, control seizures/agitation)
- [ ] VTE prophylaxis; nutrition; monitor for late hypercalcaemia

> [!info]- Why
> Myoglobin injures the kidney via vasoconstriction, tubular toxicity, and cast obstruction — all mitigated by early high-volume isotonic fluid maintaining urine flow; volume, not alkali or mannitol, is what protects the kidney. Hyperkalaemia is the immediate lethal risk. Standard dialysis does not clear myoglobin, so RRT is for the metabolic complications. Verified vs AAST 2024 rhabdomyolysis guideline.
