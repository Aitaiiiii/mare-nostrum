# TCA Overdose — ER Orders

> [!danger] ⚠️ SAFETY
> Reference only; adjust to local protocol and the attending. **QRS > 100 ms → sodium bicarbonate NOW.** Deterioration is rapid — continuous monitoring, low threshold to intubate. **Avoid phenytoin, class Ia/Ic/III antiarrhythmics, flumazenil.** Screen paracetamol/salicylate.

## 🔴 One Day
- [ ] **Continuous cardiac monitor + serial ECG**; large-bore IV; capillary glucose
- [ ] **Sodium bicarbonate 1–2 mEq/kg IV bolus, repeat**, for **QRS > 100 ms / ventricular arrhythmia / hypotension** → target **pH 7.5–7.55, Na 150–155**; then infusion
- [ ] **Intubate** early if coma/seizures/deteriorating; hyperventilate to same alkalotic pH
- [ ] **Seizures → benzodiazepine** (barbiturate/propofol if refractory) — **NOT phenytoin**
- [ ] Hypotension → crystalloid + bicarbonate → **noradrenaline**; refractory VT → **lidocaine**
- [ ] **Refractory cardiovascular collapse → 20% lipid emulsion**; consider **VA-ECMO** for refractory shock/arrest
- [ ] Activated charcoal if early + airway protected
- [ ] Labs: venous gas, K⁺/electrolytes, **paracetamol + salicylate levels**, coingestants; pregnancy test

## 🔵 Continuous
- [ ] Admit monitored/ICU if any toxicity — Dx: TCA overdose
- [ ] Continue bicarbonate/ventilation to maintain QRS narrowing + target pH; wean as toxicity resolves
- [ ] Serial ECG, gases, K⁺; treat hyperthermia, urinary retention (catheter), ileus
- [ ] **Asymptomatic + normal ECG + normal mentation after ~6 h → medically clear**
- [ ] **Psychiatric/risk assessment** (deliberate overdose)

> [!info]- Why
> Cardiotoxicity from sodium-channel blockade is the lethal effect, and hypertonic alkaline sodium bicarbonate both bypasses the block (Na load) and reduces drug binding (alkalosis) — titrated to the QRS. Phenytoin and class Ia/Ic/III drugs worsen the block; lidocaine (fast-off) is safe. Lipid emulsion/ECMO rescue refractory collapse, and recovery can be complete. Verified vs sodium-channel-blocker toxicity guidance.
