# Drowning — ER Orders

> [!danger] ⚠️ SAFETY
> Reference only; adjust to local protocol and the attending. **Hypoxia is the problem — ventilate/oxygenate first** (rescue breaths before compressions in drowning arrest). **No abdominal thrusts. No routine c-spine immobilisation** (only for suggestive trauma). Watch for delayed pulmonary injury.

## 🔴 One Day
- [ ] **Airway + ventilation/oxygenation FIRST**; high-flow O₂; **[arrest] 5 rescue breaths then CPR** (hypoxic arrest); intubate + PEEP/lung-protective for respiratory failure
- [ ] **NO abdominal thrusts** ("removing water"); suction as needed
- [ ] **C-spine immobilisation ONLY if suggestive mechanism** (diving/high-impact/trauma/intoxication with fall)
- [ ] Core temperature (rewarm — see [[Accidental Hypothermia]]); glucose; electrolytes; ECG (arrhythmia/long-QT precipitant)
- [ ] Consider a **precipitant** (seizure, arrhythmia, hypoglycaemia, alcohol, trauma)
- [ ] CXR, ABG/SpO₂; prolonged CPR + consider ECLS in cold-water/hypothermic arrest
- [ ] **No prophylactic antibiotics/steroids**

## 🔵 Continuous
- [ ] Disposition by symptoms: **asymptomatic + normal respiratory exam + normal SpO₂ after ~4–6 h observation → discharge**; any symptoms/hypoxaemia → admit + monitor
- [ ] Monitor for **delayed pulmonary oedema/ARDS** ([[ARDS (Acute Respiratory Distress Syndrome)]]); lung-protective ventilation if intubated
- [ ] Rewarm; correct electrolytes; treat bronchospasm; neuro/cardiac work-up for the precipitant
- [ ] Prevention counselling (supervision, barriers, life jackets)

> [!info]- Why
> Drowning is a hypoxic process, so airway/breathing (rescue breaths first) drive survival; abdominal thrusts are harmful, and routine c-spine immobilisation impedes the airway with little injury yield. Lung injury from surfactant washout can evolve over hours, so symptomatic patients are observed/admitted while asymptomatic ones with normal SpO₂ can be discharged. Verified vs drowning-resuscitation guidance.
