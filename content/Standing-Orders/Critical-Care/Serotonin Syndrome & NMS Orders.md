# Serotonin Syndrome / NMS — ER Orders

> [!danger] ⚠️ SAFETY
> Reference only; adjust to local protocol / poison centre (1367). **Stop the offending drug + cool aggressively — hyperthermia kills** (antipyretics don't work). **Bromocriptine worsens serotonin syndrome; don't give more dopamine blockers in NMS.** Extreme hyperthermia + rigidity → sedate/paralyse/intubate.

## 🔴 One Day
- [ ] **Stop the offending agent** (all serotonergic drugs in SS; the neuroleptic in NMS — restart dopaminergic if withdrawal-induced)
- [ ] **Core temperature** monitoring; **aggressive external cooling** (active if severe)
- [ ] **Benzodiazepines** for agitation/rigidity/autonomic hyperactivity; IV fluids
- [ ] Distinguish: **SS = rapid onset + clonus/hyperreflexia (Hunter criteria)** · **NMS = slow onset + lead-pipe rigidity + bradyreflexia + very high CK**
- [ ] Labs: **CK** (rhabdomyolysis), electrolytes (K⁺), renal/liver, venous gas/lactate, coagulation (DIC), CBC, glucose; exclude mimics (sepsis, CNS infection, heat stroke, thyroid storm)
- [ ] **[Serotonin syndrome] Cyproheptadine PO/NG** (moderate–severe) — **NOT bromocriptine**
- [ ] **[NMS] Dantrolene ± bromocriptine/amantadine** — **avoid further dopamine antagonists**
- [ ] **Extreme hyperthermia + rigidity → sedation + non-depolarising paralysis + intubation** (abolish heat production)
- [ ] Treat rhabdomyolysis/AKI/hyperkalaemia

## 🔵 Continuous
- [ ] Admit monitored/ICU — Dx: serotonin syndrome / NMS
- [ ] Continue cooling + benzodiazepines + specific therapy; serial temp, CK, K⁺, renal function
- [ ] **Undifferentiated → cyproheptadine trial first; no response in 24–48 h → consider dantrolene/bromocriptine (NMS)**
- [ ] SS usually resolves ~24 h after stopping drug; NMS prolonged (days–weeks) — monitor accordingly
- [ ] Medication review + safe re-introduction plan; psychiatry/pharmacy liaison

> [!info]- Why
> Both are drug-induced hyperthermic emergencies where stopping the trigger, cooling, and benzodiazepines are the shared core; the specific antidotes are opposite (cyproheptadine blocks serotonin in SS; dantrolene/dopaminergics treat NMS), and using the wrong one (bromocriptine in SS, dopamine blockers in NMS) worsens the syndrome. Severe hyperthermia is fatal, so paralysis/intubation abolishes muscular heat production. Verified vs SS/NMS guidance.
