# CPVT (Catecholaminergic Polymorphic VT)

> Inherited channelopathy · companion: [[Sudden Cardiac Death — Approach & Risk Stratification]] · [[Long QT Syndrome]] — *populated 26 ก.ค. 2026 จาก digest SNC4 + verification (2022 ESC VA/SCD)*
> 

# 🧬 Etiology & Pathophysiology

**CPVT** เกิดจากความผิดปกติของ **calcium handling** ใน sarcoplasmic reticulum — ยีน **RYR2** (ryanodine receptor, **AD, พบบ่อยสุด**) และ **CASQ2** (calsequestrin, **AR**) — เมื่อมี **catecholamine surge** (ออกกำลัง/อารมณ์) เกิด **diastolic Ca²⁺ leak** → **delayed afterdepolarization (DAD)** → **bidirectional / polymorphic VT** ในหัวใจที่ **โครงสร้างปกติและ resting ECG ปกติ** (QTc ปกติ) — จึงมักถูกมองข้าม

# 🩻 Diagnosis

- **Exercise stress test = แกนวินิจฉัย** — reproduces **PVC → bidirectional VT (QRS axis สลับ 180°) → polymorphic VT** ที่ threshold HR (~110–130); Holter/emotional stress ก็ induce ได้
- **Resting ECG ปกติ** (ต่างจาก LQTS/Brugada) — sinus bradycardia อาจพบ
- **Genetic testing** (RYR2/CASQ2) ยืนยัน + cascade screening ญาติ
- Ddx: LQTS, Andersen-Tawil (bidirectional VT + U wave), digoxin toxicity

# 💊 Management

- **Beta-blocker = first-line: nadolol** (non-selective, ครอบคลุมยาวนาน) — titrate ตาม exercise test
- **Flecainide add-on (Class I, 2022 ESC)** — block RyR2 Ca leak โดยตรง + Na block; เพิ่มเมื่อ BB คุมไม่ได้
- **Left cardiac sympathetic denervation (LCSD)** — refractory
- **ICD:** aborted SCA (I) — **ต้องให้ร่วมกับ beta-blocker เสมอ** เพราะ ICD shock เองกระตุ้น catecholamine → electrical storm ได้
- **จำกัดการออกกำลัง/กีฬาแข่งขัน**; หลีกเลี่ยง sympathomimetics

> 🚨 **STRICT AVOIDANCE / RED FLAGS**
> 

> - **resting ECG ปกติ ไม่ตัด CPVT ทิ้ง** — เด็ก/วัยรุ่นที่ syncope/SCA ขณะออกกำลัง/ตกใจ ต้องทำ exercise test
> 

> - **ICD เดี่ยวๆ อันตราย** — shock → catecholamine → VT storm; ต้องคู่ beta-blocker เสมอ
> 

> - หลีกเลี่ยง **sympathomimetics, competitive sport**
> 

> - **bidirectional VT = คิดถึง CPVT (หรือ digoxin toxicity)**
> 

# 🎯 High-Yield Recall

- **RYR2 (AD) / CASQ2 (AR)** → Ca leak → DAD → **bidirectional VT** จาก catecholamine; ECG พัก + โครงสร้างหัวใจ **ปกติ**
- **Dx = exercise stress test** (bidirectional/polymorphic VT); genetic
- **Tx = nadolol first-line + flecainide (Class I) + LCSD**; ICD ต้องคู่ BB
- เด็ก/วัยรุ่น syncope ขณะออกกำลัง/ตกใจ = สงสัย CPVT
