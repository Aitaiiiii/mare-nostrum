# Herpes Zoster & Zoster Vaccination

> **Source:** บรรยาย PMK Board Review (GSK symposium — อ.นวนิศ/อ.ธิติวัตร) — Zoster Vaccination ในผู้สูงอายุ≥ 50 + comorbidities | สืบค้นเพิ่ม: 28 มิ.ย. 2569
> 

> 🎯 **Key takeaway (อาจารย์ย้ำ):** จำง่าย — **อายุ≥ 50 ปี หรือ มีโรคร่วม (เบาหวาน/ไต/หัวใจ/ปอด) หรือ immunocompromised → ให้ RZV** (โรคไตเป็นได้ทุก stage). เหตุผลเดียวที่ prevention ได้คือ vaccination (recurrence หลังหาย 10–30%)
> 

## 🧬 Etiology & Molecular Pathophysiology

**Herpes Zoster (HZ) = Varicella-Zoster Virus (VZV) reactivation** — VZV ติดครั้งแรกเป็น chickenpox แล้วไปซ่อนที่ **dorsal root ganglia** (sensory nerve roots) ตลอดไป เมื่อ cell-mediated immunity ลดลงจาก aging หรือ immunosuppression → VZV reactivates → dermatomal rash + pain

**Epidemiology**:

- ประชากรไทยอายุ ≥ 50 ปี → seropositive VZV ~99%
- 1 ใน 3 คนจะ reactivate เป็น HZ ตลอดชีวิต
- Recurrence: CKD เสี่ยง recurrence เพิ่ม 34%, DM +12%
- **Risk สูง ใน CKD**: CKD non-dialysis ×1.2, HD ×1.4, PD ×1.8, Kidney transplant (risk สูงสุด)

**กลไกที่ cellular immunity ลดลง → VZV reactivation**:

- Aging (อายุ ≥ 50 ปี): immunosenescence
- Immunosuppressive drugs: corticosteroids, calcineurin inhibitors, anti-CD20 agents
- Hematologic malignancy + chemo: Bone marrow transplant เสี่ยง ×9 เทียบกับ normal population
- Chronic disease: DM, COPD, CVD, CKD, HIV
- ยากดภูมิสำหรับ autoimmune disease (biologics, JAK inhibitors)

## 🩺 Clinical Phenotypes & Advanced Nuances

### Presentations

- **Classic HZ**: dermatomal vesicular rash (เจ็บ/แสบก่อนออกตุ่ม 3–5 วัน), T1–T12 บ่อยที่สุด
- **Herpes Zoster Ophthalmicus**: อันตราย — ตุ่มน้ำเหนือคิ้วตา + ตามัว → ปรึกษา ophthalmology ทันที
- **Ramsay Hunt**: Facial nerve → Ear pain + vesicles + facial palsy
- **Disseminated HZ**: ใน immunocompromised → พบในหลาย dermatomes หรือ organ involvement

### Complications

- **Post-herpetic Neuralgia (PHN)**: พบ 27–70% สูงขึ้นในผู้สูงอายุ — ยาแก้ปวดทำให้ sedation → เสี่ยง fall ในผู้สูงอายุ
- **CV events**: ใน 1 เดือนหลัง HZ → TIA/Stroke เพิ่ม 78%, MI เพิม 68%
- **Encephalitis, Myelitis, Meningitis**: โดยเฉพาะใน immunocompromised
- **Acute retinal necrosis (ARN)**: เอาจริงจากคีนีก (เคส VZV ophthalmicus ที่ delay diagnosis → VA drop)
- **CKD progression**: HZ เพิ่ม risk developing ESRD 36% — โดยเฉพาะถ้ามี DM+HT ร่วม เสี่ยง ×8.6

### Overall complication rate: เกิดได้ ≈30% ในผู้ที่มี comorbidity

## 🩻 Advanced Diagnostics & Formal Criteria

### Diagnosis

- Dermatomal vesicular rash: Clinical diagnosis ไม่ต้องตรวจเพิ่ม
- Atypical/disseminated: PCR from vesicle fluid, DFA, Viral culture
- **ไม่ต้องตรวจเลือดขั้ง** ก่อนฉีดวัคซีน — คนไทยอายุ ≥ 50 ปี seropositive ~99% อยู่แล้ว

### เกณฑ์ให้ Zoster Vaccine

| กลุ่ม | คำแนะนำ |
| --- | --- |
| อายุ ≥ 50 ปี (general population) | **ให้ RZV (Recombinant Zoster Vaccine) 2 doses ห่างกัน 2–6 เดือน** |
| CKD (ทุก stage รวม dialysis) | ให้ RZV (ไม่ contraindicated) |
| Kidney transplant | **ให้ RZV เท่านั้น** (ZVL เป็น absolute contraindication ใน transplant) — ควรให้อย่างน้อย 2 สัปดาห์ก่อน transplant; ถ้า transplant ไปแล้วให้รอ 3–6 เดือน |
| Immunocompromised อื่นๆ (HIV, heme malignancy, ยากดภูมิ) | RZV ให้ได้ (ไม่ live) — ประสิทธิภาพลดลงนิด หากยากดภูมิสูง |
| DM, CVD, COPD | ให้ RZV (high risk ของ reactivation + complications) |
| คนที่เคยเป็น HZ มาแล้ว | ยังให้ได้ — รออย่างน้อย 3–6 เดือนหลัง rash หาย |
| อายุ < 50 ปี, ไม่มี immunocompromise | ยังไม่ FDA-approved — ให้รอจนถึง 50 ปี |

## 💊 Management & Pharmacodynamics

### รักษา Active Herpes Zoster

- **Antiviral ภายใน 72 ชั่วโมงจาก rash onset** (หลัง 72 ชม. ประสิทธิภาพลดลงมาก)
- Acyclovir / Valacyclovir / Famciclovir 7–10 วัน
- ใน CKD: **ปรับ dose ตาม GFR** — Acyclovir ทำให้ nephrotoxic ถ้าไม่ hydrate ดี
- PHN: Gabapentin, Pregabalin, TCAs, Lidocaine patch, Opioids (ระวัง sedation + fall ในผู้สูงอายุ)

### Zoster Vaccine: ZVL vs RZV

| Property | **ZVL** (Zostavax, Live Attenuated) | **RZV** (Shingrix, Recombinant) |
| --- | --- | --- |
| Platform | Live attenuated VZV | Glycoprotein E + AS01B adjuvant |
| Schedule | 1 dose | **2 doses ห่างกัน 2–6 เดือน** |
| Efficacy (age 60–69) | 61.1% | **97.2%** |
| Efficacy (age ≥ 70) | 55.4% | **91.3%** |
| PHN prevention | − | 91.2–92% |
| Duration | ลดลงเร็ว (< 5 ปี) | ≥ 11 ปี (model: ~20 ปี) |
| Immunocompromised | **Contraindicated** | ใช้ได้ |
| Pregnancy | Contraindicated | ยังไม่มีข้อมูล |

### Adjuvant System AS01B (ใน Shingrix)

- **Liposome**: delivery vehicle
- **MPL (Monophosphoryl lipid A จาก Salmonella)**: กระตุ้น innate immunity ผ่าน TLR4
- **QS-21 (Saponin จากเปลือกต้นสบู่กระด้าง)**: กระตุ้น T-cell + B-cell + macrophage

ผล: immune response เพิ่มขึ้นสูงมาก → waning ช้ากว่า live vaccine → ป้องกันได้นานกว่า 10 ปี

### Adverse Effects ของ RZV

- **Injection site pain**: 68% (สูงมาก — ต้อง inform คนไข้ก่อนเสมอ) — อยู่ 1–2 วัน
- Local redness/swelling, Fatigue, Fever (13%)
- ทั้งหมดอาการเป็นชั่วคราว ไม่เป็นอันตราย

### Booster

ตาม follow-up 11 ปี: ยังป้องกันได้ 87.7% (age 50+) — Mathematical model แสดงว่า cell-mediated immunity ยังสูงที่ 20 ปี → **ไม่จำเป็น booster หลัง 2-dose course**

### การให้วัคซีนในสถานการณ์พิเศษ

- **เคยได้ ZVL มาก่อน**: สามารถเปลี่ยนเป็น RZV ได้หลังจาก ZVL ครบ 2 เดือน (immunity จาก ZVL เริ่มลดหลังปีที่ 5–7)
- **Immunocompromised + จะส่ง transplant**: ให้ RZV อย่างน้อย 2 สัปดาห์ก่อน transplant; ถ้า transplant ไปแล้ว รอ 3–6 เดือน (ยา immunosuppressive น้อยลง → response ดีขึ้น)
- **Efficacy ใน immunocompromised**: Autologous HSCT 68.2%, Hematologic malignancy 87.2%

## 📚 Landmark Trials & Literature

| Trial | Key Finding |
| --- | --- |
| **ZOE-50** | RZV ป้องกัน HZ 97.2% ในอายุ 50–69 ปี |
| **ZOE-70** | RZV ป้องกัน HZ 91.3% ในอายุ ≥ 70 ปี |
| **ZOE-50+70** | PHN prevention 91.2%; Ophthalmic HZ prevention 93.7% |
| **ZOSTER-006 (HSCT)** | RZV ป้องกัน HZ ใน autologous HSCT 68.2% |
| **ZOSTER-039 (Heme Malignancy)** | Efficacy 87.2% แม้ได้ chemo |
| **11-year follow-up** | Efficacy 87.7% (age 50+) — no booster needed |
