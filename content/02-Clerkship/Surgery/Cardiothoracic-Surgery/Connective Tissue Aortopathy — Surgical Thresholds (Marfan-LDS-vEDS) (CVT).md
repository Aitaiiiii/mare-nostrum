## 1. ⚙️ Principle — ทำไม threshold ต่ำกว่า sporadic

connective tissue disease (heritable thoracic aortic disease, HTAD) — ผนัง aorta อ่อนแอจาก defect ของ extracellular matrix (fibrillin ใน Marfan, TGF-β signaling ใน LDS, type III collagen ใน vEDS) → dissection/rupture เกิดที่ diameter เล็กกว่า sporadic — จึงต้อง **ผ่าตัดเชิงป้องกันที่ size เล็กกว่า 5.5 cm ที่ใช้ใน sporadic** (→ C3)

แก่นคิด: **ยิ่ง defect รุนแรง threshold ยิ่งต่ำ** (vEDS < LDS < Marfan < bicuspid < sporadic) — และเน้น genotype-specific (โดยเฉพาะ LDS)

## 2. 📏 Threshold by syndrome (2022 ACC/AHA)

| Syndrome | Surgical threshold (root/ascending) | หมายเหตุ |
| --- | --- | --- |
| **Marfan (FBN1)** | **≥5.0 cm** (Class I); **≥4.5 cm**  • high-risk feature; CSA/height ≥10 cm²/m | high-risk = family hx dissection, rapid growth, diffuse dilation, vertebral tortuosity |
| **Loeys-Dietz (TGFBR1/2, SMAD3, TGFB2/3)** | **≥4.5 cm** (หรือต่ำกว่า) — **genotype-specific** | TGFBR1/2 aggressive ที่สุด; ขึ้นกับ variant + growth + extra-aortic + sex/size |
| **vEDS (COL3A1)** | ไม่ใช้ size เดี่ยว — dissection ที่ diameter ปกติ; medical เน้น (ดูข้างล่าง) | tissue เปราะมาก — surgery เสี่ยงสูง |
| **Bicuspid aortic valve (BAV)** | **≥5.5 cm**; ≥5.0 cm + risk factor/experienced center; **≥4.5 cm ขณะ AVR** | ไม่เท่า Marfan/LDS — threshold สูงกว่า |
| **Turner syndrome** | **ASI (aortic size index) >2.5 cm/m²** | คนตัวเล็ก → index ต่อ BSA |

**Rapid growth** (ทุก HTAD): ≥ 0.3 cm/1 ปี (เทียบ sporadic ≥ 0.5 cm/1 ปี) — เป็น indication เอง

**Pre-pregnancy (Marfan):** ผ่าตัดก่อนตั้งครรภ์ถ้า root **>4.5 cm** (หรือ 4.0–4.5 cm + risk factor) — เพราะ hemodynamic/hormonal ขณะตั้งครรภ์เร่ง dilation/dissection

## 3. 🧬 vEDS — กรณีพิเศษ

vascular Ehlers-Danlos (COL3A1, type III collagen defect) — ต่างจาก Marfan/LDS:

- **spontaneous arterial dissection/rupture ที่ diameter ปกติ** — size threshold ใช้ไม่ได้
- **tissue เปราะมาก** — surgery/anastomosis เสี่ยง bleeding/suture line failure → เน้น medical + หลีก elective intervention ถ้าทำได้
- **celiprolol** (beta-blocker) — ลด arterial event ใน vEDS (หลักฐานเฉพาะ)

## 4. 🚦 Open > TEVAR (กฎความปลอดภัย)

**สำหรับ Marfan/LDS/vEDS — open surgery เหนือกว่า TEVAR (เมื่อ descending TAA เข้าเกณฑ์)**:

- stent-graft ใน native aorta ที่เปราะจาก connective tissue defect → SINE, further dissection, endoleak, migration — radial force ของ stent ทำร้าย fragile wall
- TEVAR ใช้ได้เฉพาะ emergency/bridge หรือ landing ใน surgical graft ที่วางไว้ก่อน (เช่น FET graft → C4)
- ใช้ branched graft (ไม่ island) ใน total arch เพราะ island patch ของ native tissue จะ dilate (→ C4)

## 5. 💊 Medical + surveillance

- **beta-blocker หรือ ARB** (maximally tolerated) — ลด rate of aortic dilation ใน Marfan; combination ก็ได้ (Class IIa)
- **surveillance:** Marfan/LDS — TTE + CT/MRI ประจำปี; LDS — head-to-pelvis CT/MRI (aorta ทั้งเส้น + tortuosity); เริ่มต้นที่ 6 เดือนดู growth rate
- **genetic testing** — แนะ broad ใน TAA + syndromic feature/<60 ปี/BAV/family history + screen first-degree relatives
- วัด diameter 2022: leading-edge-to-leading-edge (TTE), internal diameter (CT) — เปลี่ยนจาก 2010 → concordance ดีขึ้น

<aside>
🚨

**STRICT AVOIDANCE / RED FLAGS**

- **อย่ารอ threshold sporadic (5.5 cm) ใน connective tissue disease** — dissection เกิดที่ size เล็กกว่า; Marfan ≥5.0/≥4.5+risk, LDS ≥4.5
- **อย่าทำ TEVAR ใน Marfan/LDS/vEDS เป็น primary** — SINE/further dissection; open เป็นหลัก (กฎความปลอดภัย)
- **ระวัง vEDS — surgery เสี่ยงมาก (tissue เปราะ)** — medical (celiprolol) เน้น; หลีก elective ถ้าทำได้
- **อย่าลืม pre-pregnancy repair ใน Marfan root >4.5 cm** — dissection risk ช่วงตั้งครรภ์/คลอด
- **อย่าลืม screen first-degree relatives** — HTAD ถ่ายทอด autosomal dominant
</aside>

<aside>
🎯

**High-Yield Recall**

- **Threshold ต่ำกว่า sporadic:** Marfan ≥5.0 (/≥4.5+risk) · LDS ≥4.5 (genotype-specific) · BAV ≥5.5 (/≥4.5 ขณะ AVR) · Turner ASI >2.5 cm/m²
- **vEDS** — dissection ที่ size ปกติ, tissue เปราะ → medical (celiprolol) เน้น, surgery เสี่ยง
- **Open > TEVAR** ใน Marfan/LDS/vEDS — stent ใน fragile wall → SINE/dissection
- **Rapid growth HTAD:** ≥0.3 cm/1yr (เทียบ sporadic ≥0.5)
- **Pre-pregnancy Marfan:** root >4.5 cm → ผ่าตัดก่อน
- **Medical:** beta-blocker/ARB (max tolerated) + surveillance + genetic testing + screen relatives
</aside>
