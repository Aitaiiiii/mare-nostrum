# 🩸 1. Coronary Revascularization

กลุ่มนี้คือการเปิดเส้นเลือดใหม่ให้กล้ามเนื้อหัวใจที่ขาดเลือด — เป็นหัตถการของ cardiac surgery

| Procedure | ทำอะไร / ใช้เมื่อไหร่ | ชื่อ/ที่มา |
| --- | --- | --- |
| **CABG** (Coronary Artery Bypass Grafting) | ต่อทางเบี่ยงเลือดข้ามตำแหน่งตีบด้วย graft — ใช้ใน multivessel/left main CAD | common name |
| **LIMA-LAD graft** | เอา **left internal mammary artery (LIMA)** ต่อกับ LAD — patency ระยะยาวที่สุด (>90% ที่ 10 ปี) เป็น gold-standard graft | common (LIMA = IMA/mammary) |
| **On-pump CABG** | CABG ที่ใช้ cardiopulmonary bypass + arrest หัวใจ | common |
| **OPCAB** (Off-Pump CABG) | CABG บนหัวใจที่ยังเต้นอยู่ ไม่ใช้ bypass — ลด CPB-related complication แต่ technically ยากกว่า | common |
| **MIDCAB** (Minimally Invasive Direct CAB) | LIMA-LAD ผ่าน small left thoracotomy ไม่ต้องผ่า sternotomy | common |
| **PCI** (Percutaneous Coronary Intervention) | ขยายหลอดเลือดด้วย balloon + stent ผ่าน catheter | common |
| **Vineberg procedure** | ฝัง IMA เข้าไปใน myocardium โดยตรง (ก่อนยุค anastomosis) — ต้นแบบทางประวัติของ surgical revascularization, เลิกใช้แล้ว | Arthur **Vineberg** (Canadian, 1903–1988) |

# 🫀 2. Valve Surgery (Open / Surgical)

## 2A. Aortic valve

- **SAVR** (Surgical Aortic Valve Replacement) — เปลี่ยนลิ้น aortic ด้วย prosthesis (mechanical/bioprosthetic) ผ่าน sternotomy — ใช้ใน severe symptomatic AS/AR ที่เหมาะ surgery; benchmark ของ TAVR (ดู [Prosthetic Heart Valves — Mechanical vs Bioprosthetic, PPM, Thrombosis & Selection Algorithm](Prosthetic%20Heart%20Valves%20%E2%80%94%20Mechanical%20vs%20Bioprosthe%203a0224abad818181b78bf696a7cb4e0f.md))
- **Ross procedure (pulmonary autograft)** — เอา **pulmonary valve ของผู้ป่วยเอง (autograft)** มาแทน aortic valve แล้วใส่ **homograft** ที่ตำแหน่ง pulmonary — ข้อดีคือ autograft มีชีวิต โตตามได้ ไม่ต้อง anticoagulate เหมาะเด็ก/หญิงวัยเจริญพันธุ์/young adult; ข้อเสียคือกลายเป็น double-valve disease ถ้า fail ตั้งชื่อตาม Donald **Ross** (British surgeon, 1922–2014) — *(ระวังสับสนกับ Ross classification ของ HF ในเด็ก)*
- **Konno procedure (Konno-Rastan, aortoventriculoplasty)** — ผ่าขยาย **LVOT + annulus** โดยกรีดผ่าน septum เพื่อใส่ลิ้นขนาดใหญ่ขึ้น ใน **tunnel/annular subaortic stenosis** ที่ annulus เล็ก; **Ross-Konno** = ทำร่วมกับ Ross ตั้งชื่อตาม Souji **Konno** และ Sir Donald **Ross**/**Rastan**
- **Morrow procedure (septal myectomy)** — ตัดกล้ามเนื้อ **basal interventricular septum** ออก เพื่อลด **LVOT obstruction ใน HOCM** — surgical gold standard ของ HOCM ที่ดื้อยา ตั้งชื่อตาม Andrew Glenn **Morrow** (American, 1922–1982); *(Brockenbrough sign เป็น hemodynamic sign ของโรคนี้ — ดู [Cardiovascular Physical Examination Eponyms](Cardiovascular%20Physical%20Examination%20Eponyms%20(Signs%203a4224abad8181b2b576c4ecae388473.md))*
- **Commando procedure** — ผ่าตัดใหญ่เปลี่ยนทั้ง aortic valve, mitral valve และ reconstruct **intervalvular fibrous body** ใน extensive double-valve/annular destruction (เช่น endocarditis รุนแรง) — common name ("commando" = ยากและ aggressive)

## 2B. Mitral valve

- **Mitral valve repair** — ซ่อมลิ้นแทนเปลี่ยน (annuloplasty ring, leaflet resection, neochord) — เป็น first choice ใน primary MR ที่ซ่อมได้ (ดู [MR (Mitral Regurgitation) — Primary vs Secondary, COAPT/MITRA-FR & 2025 ESC Algorithm](MR%20(Mitral%20Regurgitation)%20%E2%80%94%20Primary%20vs%20Secondary,%20%203a0224abad8181f5980ed4b8686fd0f9.md))
- **Alfieri stitch (edge-to-edge repair, "double-orifice")** — เย็บขอบ anterior กับ posterior leaflet ตรงกลางเข้าด้วยกัน ทำให้เกิด **double-orifice mitral valve** ลด MR — เป็น surgical ต้นแบบของ **MitraClip / M-TEER** ตั้งชื่อตาม Ottavio **Alfieri** (Italian surgeon)
- **Wooler / Kay annuloplasty** — เทคนิค suture annuloplasty ยุคแรกสำหรับลด annular dilation — historical, ปัจจุบันใช้ ring annuloplasty แทน

## 2C. Tricuspid valve

- **De Vega annuloplasty** — **suture (purse-string) annuloplasty** รอบ tricuspid annulus เพื่อลด functional TR โดยไม่ใช้ ring — ทางเลือกที่เร็ว/ถูกกว่า ring ตั้งชื่อตาม Norberto **De Vega** (Spanish surgeon)
- **Ring annuloplasty (tricuspid)** — ใส่ prosthetic ring ลด annular dilation — durable กว่า De Vega ใน severe functional TR

# 🩸 3. Aortic Root, Ascending & Arch Surgery

กลุ่ม eponym ที่หนาแน่นที่สุด — แกนคือ **จะเก็บลิ้น aortic ไว้ได้ไหม (valve-sparing) หรือต้องเปลี่ยนทั้ง composite** ใช้ใน aortic root aneurysm / type A dissection / Marfan

| Procedure | ทำอะไร | เก็บลิ้นเดิม? |
| --- | --- | --- |
| **Bentall procedure** | เปลี่ยน **aortic valve + root + ascending aorta** ด้วย **composite valved graft** แล้ว reimplant coronary ostia ("buttons") เข้ากับ graft | ❌ เปลี่ยนลิ้น (mechanical/bio) |
| **David procedure** | **valve-sparing reimplantation** — เอา root ออกใส่ Dacron graft แต่ **reimplant native valve เข้าไปในกราฟต์** | ✅ เก็บลิ้นเดิม |
| **Yacoub procedure (remodeling)** | valve-sparing แบบ **remodeling** — เย็บ graft เป็น neo-sinuses รอบ native valve (ไม่ห่อ annulus) | ✅ เก็บลิ้นเดิม |
| **Cabrol procedure** | variant ของ Bentall — เชื่อม coronary ด้วย **interposition graft (Cabrol graft)** เมื่อ coronary button ตึงเกินไป reimplant ตรงไม่ได้ | ❌ (เป็น coronary-handling variant) |
| **Wheat procedure** | เปลี่ยน **aortic valve + ascending aorta แต่เก็บ sinuses/coronary ไว้** (ไม่แตะ root) — ใช้เมื่อ root ปกติ | ❌ เปลี่ยนลิ้น เก็บ root |
- **Bentall**: Hugh **Bentall** (British, 1920–2012) — composite graft, 1968; "button Bentall" = เทคนิคปัจจุบัน
- **David**: Tirone **David** (Canadian surgeon) — valve-sparing reimplantation, 1992 (David I–V เป็น sub-technique)
- **Yacoub**: Sir Magdi **Yacoub** (Egyptian-British surgeon) — remodeling technique
- **Cabrol**: Christian **Cabrol** (French surgeon, 1925–2017 — ทำ heart transplant ครั้งแรกในยุโรป)

## Arch & dissection techniques

- **Elephant trunk / Frozen elephant trunk (FET)** — วาง graft ส่วนปลายลอยเข้าไปใน descending aorta ("งวงช้าง") เพื่อทำ arch replacement เป็น staged approach; **frozen** = ใช้ stent-graft hybrid — common name
- **Hemiarch / Total arch replacement** — เปลี่ยน arch บางส่วน/ทั้งหมด — common name
- **TEVAR** (Thoracic Endovascular Aortic Repair) — วาง stent-graft ใน descending thoracic aorta ผ่าน catheter — ใช้ใน type B dissection/aneurysm — common name
- **EVAR** (Endovascular Aneurysm Repair) — stent-graft สำหรับ abdominal aortic aneurysm — common name

| **Konno / Ross-Konno** | ขยาย LVOT (ดูหมวด 2A) | Konno |
| **Nikaidoh** | aortic translocation ใน TGA/VSD/PS ที่ซับซ้อน | Hisashi **Nikaidoh** |

# 🎈 5. Transcatheter / Structural Interventions

> ⚠️ ข้อมูล approval/trial ด้านล่างเป็นสถานะ ณ **~2024–2025** — เปลี่ยนเร็ว ตรวจ guideline ล่าสุดก่อนอ้างอิงทางคลินิก
> 

## 5A. Aortic

- **TAVR/TAVI** (Transcatheter Aortic Valve Replacement/Implantation) — วางลิ้น aortic ผ่าน catheter (มัก transfemoral) ปัจจุบัน **จำนวน TAVR ในสหรัฐฯ แซง SAVR แล้ว** และมีหลักฐานครอบคลุมทุก surgical risk (PARTNER, Evolut series); ล่าสุด **EARLY TAVR** ขยายไปสู่ asymptomatic severe AS, **PARTNER 3 7-year data** — first-in-human โดย Alain **Cribier** (French, Rouen 2002) → เพจเต็ม [TAVR (Transcatheter Aortic Valve Replacement) — Evidence, Valve Technology & Complications](TAVR%20(Transcatheter%20Aortic%20Valve%20Replacement)%20%E2%80%94%20Ev%203a0224abad818134a2c8cc2f1c7a011a.md)
- **BAV** (Balloon Aortic Valvuloplasty) — ขยายลิ้น AS ด้วย balloon — bridge/palliative, restenosis เร็ว — common name
- **Valve-in-valve (ViV)** — วาง TAVR ในลิ้น bioprosthetic ที่ degenerate — common name

## 5B. Mitral

- **M-TEER / MitraClip** (Mitral Transcatheter Edge-to-Edge Repair) — clip ขอบ leaflet แบบ Alfieri ผ่าน catheter ลด MR; approved ทั้ง degenerative และ functional MR (**COAPT** = pivotal ใน secondary MR); ต้นแบบคือ **Alfieri stitch** — common name (MitraClip = ยี่ห้อ Abbott)
- **PASCAL** — อีก TEER device (edge-to-edge) — common/brand
- **TMVR** (Transcatheter Mitral Valve Replacement) — เปลี่ยนลิ้น mitral ทั้งตัวผ่าน catheter; **Tendyne (Abbott) เป็น TMVR ตัวแรกที่ FDA approve พ.ค. 2025** สำหรับ high-risk + mitral annular calcification ที่ทำ M-TEER ไม่ได้; **Sapien M3** ก็ได้รับ approval; Achilles heel คือ **LVOT obstruction** — common name
- **Percutaneous mitral balloon valvuloplasty (PMBV/PMBC)** — ขยาย rheumatic MS ด้วย **Inoue balloon** — ตั้งชื่อตาม Kanji **Inoue** (Japanese)

## 5C. Tricuspid

- **T-TEER / TriClip** (Tricuspid TEER) — clip ขอบ tricuspid leaflet; **FDA approve เม.ย. 2024** จาก **TRILUMINATE Pivotal** → routing [TR (Tricuspid Regurgitation) — The Forgotten Valve, Ventricular Interdependence & TRILUMINATE](TR%20(Tricuspid%20Regurgitation)%20%E2%80%94%20The%20Forgotten%20Valve%203a0224abad8181938228d555b008509b.md)
- **TTVR / EVOQUE** (Transcatheter Tricuspid Valve Replacement) — เปลี่ยนลิ้น tricuspid ผ่าน catheter; **EVOQUE FDA approve ก.พ. 2024** จาก **TRISCEND II**; ใช้เมื่อไม่เหมาะ T-TEER (แต่ complication เช่น conduction disturbance/bleeding มากกว่า) — common/brand

## 5D. Other structural / LAA / septal / MCS-adjacent

- **LAAO** (Left Atrial Appendage Occlusion) — ปิด LAA ลด stroke ใน AF ที่ทน anticoagulant ไม่ได้; device: **WATCHMAN**, Amulet — common/brand
- **ASD/PFO/VSD device closure** — ปิดรูด้วย occluder (เช่น Amplatzer) ผ่าน catheter — common/brand
- **Balloon atrial septostomy (Rashkind procedure)** — ฉีก atrial septum ด้วย balloon เพิ่ม mixing ใน d-TGA ทารก ตั้งชื่อตาม William **Rashkind**
- **Alcohol septal ablation (ASA)** — ฉีด alcohol เข้า septal perforator ทำให้ septum ที่อุด LVOT ตายลง — ทางเลือก percutaneous แทน Morrow myectomy ใน HOCM — common name
- **Impella / IABP / ECMO / TandemHeart** — mechanical circulatory support (ดูรายละเอียดใน MCS device pages ถ้ามี) — common/brand

# ⚡ 6. Arrhythmia / EP Surgical & Ablation Procedures

- **Cox-Maze procedure (Maze III/IV)** — สร้างแนวแผล (cut-and-sew เดิม / ปัจจุบัน cryo-RF) ใน atrium เพื่อตัดวงจร reentry รักษา **AF** — surgical gold standard; มักทำร่วมกับ valve/CABG ตั้งชื่อตาม James **Cox** (ดูใน [ECG & Electrophysiology Eponyms](ECG%20&%20Electrophysiology%20Eponyms%20(Medical%20Eponym%20Re%203a4224abad8181f1ba1ec23df0d2a1c8.md) หมวด Miscellaneous ด้วย)
- **Catheter ablation (PVI)** — Pulmonary Vein Isolation ด้วย RF/cryo/PFA สำหรับ AF — common name
- **AV node ablation + pacemaker ("ablate and pace")** — ทำลาย AV node + ใส่ pacemaker ควบคุม rate ใน AF ที่คุม rate ไม่ได้ — common name
- **Surgical LAA exclusion / clip (AtriClip)** — ตัด/หนีบ LAA ตอนผ่า cardiac surgery ลด stroke — common/brand
- **ICD / CRT implantation** — device สำหรับ SCD prevention / dyssynchrony — common name (ดู device pages)

# 🔧 7. Transplant, MCS & Ventricular Remodeling

- **Orthotopic heart transplant** — เปลี่ยนหัวใจทั้งดวง; เทคนิค anastomosis: **biatrial (Lower-Shumway)** ดั้งเดิม vs **bicaval** ปัจจุบัน (ลด atrial arrhythmia/TR) ตั้งชื่อตาม Norman **Shumway** (บิดา US heart transplant) และ Richard **Lower**
- **Heterotopic ("piggyback") transplant** — วางหัวใจ donor คู่ขนานกับหัวใจเดิม — historical/หายาก
- **LVAD / RVAD / BiVAD** — Ventricular Assist Device เป็น bridge-to-transplant/destination — common name (ดู MCS pages)
- **Batista procedure (partial left ventriculectomy)** — ตัดกล้ามเนื้อ LV ออกส่วนหนึ่งลดขนาดห้อง ใน DCM — ตั้งชื่อตาม Randas **Batista** (Brazilian); ⚠️ ปัจจุบัน **เลิกใช้** (ผลลัพธ์แย่) — historical
- **Dor procedure (surgical ventricular restoration, SVR/endoventricular circular patch)** — reshape LV หลัง large anterior MI aneurysm ด้วย patch — ตั้งชื่อตาม Vincent **Dor** (French); บทบาทจำกัดหลัง STICH trial
- **Pericardiectomy / pericardial window** — เอา pericardium ออกใน constrictive pericarditis / drain effusion — common name (ดู [Cardiac Tamponade](Cardiac%20Tamponade%2038a224abad8181c88c29ef4c4d355967.md))
- **PTE / PEA** (Pulmonary Thromboendarterectomy) — ลอก organized thrombus ออกจาก pulmonary artery ใน CTEPH — common name

# 🎯 High-Yield Recall

- **Coronary**: **LIMA-LAD** = graft ที่ patency ดีที่สุด (>90% ที่ 10 ปี) · CABG vs PCI ตาม anatomy/SYNTAX
- **Aortic root (คู่ที่ต้องแยกให้ออก)**: **Bentall** = composite valved graft (เปลี่ยนลิ้น) · **David** = valve-sparing reimplantation (เก็บลิ้น) · **Yacoub** = remodeling · **Cabrol** = coronary interposition graft variant
- **Aortic valve พิเศษ**: **Ross** = pulmonary autograft (โตตามได้, ไม่ต้อง warfarin) · **Konno** = ขยาย LVOT/annulus · **Morrow myectomy** = surgical treatment ของ HOCM
- **Mitral**: **Alfieri edge-to-edge** = ต้นแบบของ **MitraClip/M-TEER** · **Inoue balloon** = PMBV ของ rheumatic MS
